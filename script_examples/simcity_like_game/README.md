# Mini Metropolis (SimCity-style prototype)

A lightweight browser game inspired by SimCity where you zone land, lay roads, manage power, and grow your city.

## Run

```bash
cd script_examples/simcity_like_game
python -m http.server 8080
```

Then open <http://localhost:8080>.

## Features

- Residential, commercial, and industrial zoning.
- Roads and power plants affecting growth.
- Parks that increase city happiness.
- Bulldoze and inspect tools.
- Monthly economy and population simulation.
